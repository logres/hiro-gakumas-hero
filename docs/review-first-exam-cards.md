# 好印象首考前的选卡角色

来源：[AppGameLog：白線 葛城リーリヤ HIF 攻略](https://appgamelog.com/gkmas-hif-lilja/)（2026-06-22，核对于 2026-11-07）。作者明确区分首考与后续考试：首考尚没有后期主力兑现牌，使用手拍子、キラメキ等替代；之后才转入其后期组合。这个经验不等于所有好印象牌都有相同价值，也不保证另一账户的编成和定制条件成立。

`HIRO_REVIEW_FIRST_EXAM_ROLES=1` 默认关闭，还需开启显式身份；只应用于主数据推荐 `ExamReview`、选拔 `produce-007` 第 1–6 个日程位置。代码读取对应强化版本的实际 `produceDescriptions`，识别即时好印象兑现、再动和建立好印象，不按牌名硬套。带使用条件、资源消耗条件、延迟触发或未知定制的牌不当作已具备无条件兑现。

完整且已核对的牌组缺少即时兑现时，优先补一张。牌组条数与 `deck_size` 不符、或完整性未确认时，只能说“已记录卡未见”，在同推荐、同持有条件下作轻量偏好；完全未知的牌组不判缺失。任何可信记录已显示持有兑现牌，就取消该补缺偏好。首考之后、其他路线均保留原中立排序，不为此自动刷新。

已有基础兑现时，另允许有限的软升级：候选是未持有的无条件即时好印象兑现，倍率至少达到已记录最大倍率的 1.5 倍；只在候选均为普通一次性建立好印象或无条件兑现时比较。再动、持续引擎、条件性效果及未知定制不参加这次跨角色比较。这个 1.5 倍阈值是工程启发式，不是攻略原文的精确结论；部分牌组的最大值只称“已记录最大”，不声称全局最大。

真实 `windows-qualify-03-r4` 第 13 步记录里已有基础 100% / 130% 兑现。候选为条件性兑现兼再动、200% 兑现、可重复的建立好印象；不满足上述窄比较条件。开关前后实际均选槽 2，没有证据宣称这次历史选卡已因本规则改善。
