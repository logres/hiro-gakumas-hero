# 卡牌流转的官方依据

2026-11-07 从公开主数据 HelpContent 的名称和 detailUrl 定位，读取游戏官方帮助[スキルカードの使用手順](https://stat.game-gakuen-idolmaster.jp/html/help/b9cde558b51e1db3128dd515a881af02eb080284731bf95a4433deed87176a6a/index.html)。以下为规则摘要，不包含账号或实测截图。

- 通常回合开始从山札顶抽三张，山札不足时将弃牌洗成新山札。
- 通常每回合使用一张；卡牌及 P 道具能够改变抽牌量和使用次数。
- 手牌上限五张，超额加入手牌的卡改放山札顶。
- 使用后通常进入弃牌；一次性卡使用后除外，未使用手牌在回合结束进入弃牌。
- 除外牌不参与普通重洗，但特定效果可以使其返回牌堆或手牌。

## 对决策上下文的约束

这些是一般机制，不是当前战局的完整状态。当前抽牌量必须检查相关效果；牌堆数量和全部副本未确认时，不计算精确抽回概率。持有记录不等于当前山札，已除外牌不能按普通重洗计入机会；反过来，未知抽回机会也不等于零。

决策应区分三类证据：官方基础规则、当前已确认的规则修正、尚未观察的状态。基础规则可以解释未来机会的条件，但不能覆盖实际卡面、道具、保留效果和已确认的特殊规则。当前通用 prompt 1.11 尚未接入这份新资料；本次正在运行的 r32 不因该文档发生行为变化。

未来接入须至少核对：额外抽牌、手牌已满、山札不足、一次性除外、回收除外牌及未知牌堆。使用数学抽样公式还须明确随机分布假设；官方描述“洗牌”本身不足以证明某个未观察局面的精确概率。
